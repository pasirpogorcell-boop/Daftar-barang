Tips Keamanan Data

  • Data disimpan di browser Anda
    Semua data tersimpan di localStorage. Tidak ada data yang dikirim ke server.
  • Rutin Backup Data
    Gunakan fitur Backup & Restore di menu Pengaturan untuk menyimpan data sebagai file JSON. Backup minimal seminggu sekali.
  • Cara Restore
    Jika berganti HP atau browser, upload file backup di menu Pengaturan untuk memulihkan semua data.
  • Hapus hanya data yang dipilih
    Tombol hapus di setiap menu hanya menghapus item yang Anda pilih, data lain tetap aman.
  • Gunakan satu perangkat
    Data tidak tersinkron antar perangkat. Pastikan backup jika ingin pindah perangkat.
  • Kapan harus backup?
    Setelah selesai transaksi besar, menambah banyak pelanggan, atau setiap akhir pekan.

Fitur Kasir untuk apa?
Untuk transaksi jualan harian yang cepat. Pilih produk, atur jumlah, langsung bayar. Stok akan otomatis berkurang dan masuk ke Arus Kas.

Manajemen Stok untuk apa?
Untuk mencatat semua barang warung, harga jual, harga beli, jumlah stok, dan tanggal kadaluarsa. Kalau stok <=3 akan muncul peringatan "Menipis" di dashboard.
Cara pakai: Isi Nama-Harga Jual-Harga Beli-Stok-Expired → Tambah Produk. Pakai tombol +/- untuk stok opname, pensil untuk edit.

Arus Kas untuk apa?
Untuk tahu uang keluar-masuk selain jualan. Misal: modal awal, beli kulakan, bayar listrik. Saldo otomatis dihitung: Pemasukan - Pengeluaran.
