Informasi Aplikasi

WarungKu

Manajemen Warung Mandiri · v6.0.2

WarungKu adalah aplikasi pencatatan operasional warung berbasis browser untuk membantu pemilik warung mengelola transaksi, stok, dan keuangan harian secara mandiri tanpa koneksi server.

Fitur Utama

Kasir / POS — Transaksi cepat dengan pengurangan stok otomatis.
Manajemen Stok — Kontrol harga beli, harga jual, stok, dan kadaluarsa.
Keuangan — Arus kas, buku kasbon, hutang supplier, dan laba harian.
Cetak Struk — Generate struk thermal HD siap cetak & download PNG.
Laporan & Export — Rekap harian dan export Excel / PDF.

Penyimpanan Data

Seluruh data disimpan secara lokal di Local Storage browser perangkat Anda. Tidak ada data yang dikirim ke server eksternal. Gunakan fitur Backup di menu Pengaturan untuk mengamankan data.
